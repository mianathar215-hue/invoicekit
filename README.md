# InvoiceKit - Android App Build

This repository builds an Android APK automatically using GitHub Actions.

## How to get the APK

1. Go to the **Releases** section (right side of this page)
2. Click the latest release
3. Download **app-debug.apk**
4. Send to your Android phone
5. Install it!

## How to install on Android

1. Download the APK on your phone
2. Tap the downloaded file
3. If it says "blocked" → go to **Settings → Security → Install unknown apps → Allow**
4. Tap Install
5. Open InvoiceKit ✅

## For iPhone users

Open this link in Safari on your iPhone and tap **Share → Add to Home Screen**

## Building a new version

Every time you push changes to this repository, a new APK is built automatically. Check the **Actions** tab to see the build progress.
