iOS Install Guide
Add to iPhone Home Screen
1
Open in Safari
Open your GitHub Pages link in Safari on iPhone. Must be Safari — not Chrome.
🦁 Safari only
2
Tap Share ⬆
Tap the Share icon at the bottom of Safari — the box with an arrow pointing up.
3
Add to Home Screen
Scroll in the share sheet and tap "Add to Home Screen".
📱 Add to Home Screen
4
Tap Add
Name it "InvoiceKit" and tap Add. Done! It's on your home screen like a real app.
✅ Works offline too!
PDF on iPhone
💡
PDF opens in new tab
Tap "Download Invoice PDF" — it opens the PDF in a new Safari tab. Then tap Share ⬆ to save to Files or send via WhatsApp / Email.
GitHub Pages Setup
1
Create GitHub account
Go to github.com and sign up free.
2
New Repository
Click + → New Repository → name it "invoicekit" → Public → Create.
3
Upload index.html
Click "uploading an existing file" → drag your index.html → Commit changes.
4
Enable Pages
Settings → Pages → Branch: main → Save. Wait 1 min.
5
Your live link
yourusername.github.io/invoicekit — open this in Safari on iPhone!
🎉 Live forever, free!
